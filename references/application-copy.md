# Application Copy Reference

Use these templates for incubator, park, accelerator, and government application forms. Replace bracketed placeholders with user-provided facts.

## 企业（团队）介绍 100-400字

Template:

> `[Team/Company Name]` 聚焦 `[industry/domain]`，正在打造 `[product/service name]`，面向 `[target customer]` 解决 `[specific pain point]`。项目通过 `[core technology/workflow]`，帮助客户实现 `[measurable outcome]`。当前项目处于 `[stage: concept/MVP/pilot/commercialization]` 阶段，已完成 `[known progress]`，下一步计划在 `[market/geography/scenario]` 进行验证和落地。

Example with placeholders kept:

> `[项目/团队名称]` 聚焦 `[行业领域]`，正在打造 `[产品/服务名称]`，面向 `[目标客户]` 解决 `[核心痛点]`。项目通过 `[核心技术或工作流]`，帮助客户实现 `[业务结果]`。当前处于 `[发展阶段]`，已完成 `[阶段成果]`，下一步计划在 `[目标市场/应用场景]` 进行验证和落地。

## 核心成员及简介 100-400字

Template:

> 核心成员包括 `[Founder Name]` 及 `[team roles]`。创始人具备 `[education/background]` 和 `[years/field experience]`，曾参与 `[relevant projects]`，擅长 `[capability 1]`、`[capability 2]` 和 `[capability 3]`。团队在 `[technology/product/market/operation]` 方面具备互补能力，后续将补充 `[planned hires]`，支撑产品研发、客户验证和商业化落地。

## 项目内容摘要 300字左右，第三方客观口吻

Template:

> `[Project Name]` 是面向 `[target customer]` 的 `[product/service category]`。项目针对 `[customer workflow pain]`，通过 `[core technology/workflow]`，提供 `[key modules/functions]`，帮助客户实现 `[business outcome]`。项目当前处于 `[stage]`，已完成 `[progress]`，计划依托 `[incubator/park/city/ecosystem resources]` 开展 `[pilot/commercialization/R&D]`。未来项目将通过 `[business model]` 形成可持续收入，并在 `[market expansion direction]` 复制应用。

## 项目基本情况表短摘要

Short template:

> `[Project Name]` 是面向 `[target customer]` 的 `[product/service]`，通过 `[core workflow/technology]` 解决 `[pain point]`，帮助客户实现 `[result]`。项目处于 `[stage]`，计划在 `[market/scenario]` 完成验证和商业化落地。

## Official Form Defaults

Use placeholders when exact facts are missing:

- 企业（或项目持有人）名称：`[Founder or Company Name]`
- 项目名称：`[Project Name + short descriptor]`
- 行业领域：`[Industry category]`
- 注册时间：`尚未注册 / 待补充`
- 注册地址：`待补充`
- 注册资本：`尚未注册 / 待补充`
- 上年度纳税额：`尚未注册，暂无`
- 法人代表：`[Founder Name] / 待补充`
- 联系方式：`待补充`
- 证件类型/证件号码：`待补充`
- 团队人数/申请座位：`待补充` unless user confirms a number.
- 港澳台人数：`待补充` unless user confirms.
- 研发人员数：`待补充` unless user confirms.
- 市场人员数：`待补充` unless user confirms.
- 港澳台人员股权占比：`待补充`
- 知识产权：`暂无已授权 / 待补充`
- 融资/获资助情况：`暂未融资 / 待补充`

## Materials Checklist Notes

For project-team stage:

- 孵化项目入驻申请表：已填写，待打印签字扫描。
- 身份证明：待补充身份证明扫描件并签字。
- 商业计划书或可行性报告：待补充/已准备，按用户实际情况填写。
- 团队基本情况：待填写或已填写团队基本情况表。
- 营业执照：如尚未注册，写暂无。
- 股权证明材料：如尚未成立公司，通常暂无。
- 创新创业大赛获奖证书：如有另附；暂无则无需提供。
- 知识产权证明：如有另附；暂无则写暂无。
- 融资证明：如有另附；暂无则写暂无。
- 政府资助证明材料：如有另附；暂无则写暂无。

## Character-Limited Field Guidance

- 100字以内：只写项目对象、解决问题、产品形态和结果。
- 100-200字：加入发展阶段和落地场景。
- 200-400字：加入市场逻辑、技术应用、商业模式或团队能力。
- 官方表单：优先客观清晰，不写夸张宣传语。
