# Security Policy / 安全政策

## Reporting Security Issues / 报告安全问题

**English:**

We take security issues seriously. If you discover a security vulnerability in this project, please report it privately to avoid potential exploitation.

**How to report:**

1. **Preferred method:** Use GitHub's private vulnerability reporting feature:
   - Go to the [Security tab](https://github.com/huaxialucaicaizi/business-plan-skill/security)
   - Click "Report a vulnerability"
   - Fill in the details of the vulnerability

2. **Alternative method:** Contact the maintainer directly through GitHub:
   - Visit the [maintainer's profile](https://github.com/huaxialucaicaizi)
   - Use GitHub's private messaging or email features (if publicly available)

**Please include:**
- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Any suggested fixes (if available)

**What to expect:**
- We will acknowledge receipt of your report within 48-72 hours
- We will investigate and provide updates on the resolution timeline
- Once the issue is resolved, we will credit you in the security advisory (unless you prefer to remain anonymous)

---

**中文：**

我们非常重视安全问题。如果你在本项目中发现安全漏洞，请私下报告以避免潜在利用。

**如何报告：**

1. **首选方式：** 使用 GitHub 的私有漏洞报告功能：
   - 访问 [Security 标签页](https://github.com/huaxialucaicaizi/business-plan-skill/security)
   - 点击「Report a vulnerability」
   - 填写漏洞详情

2. **备选方式：** 通过 GitHub 直接联系维护者：
   - 访问[维护者主页](https://github.com/huaxialucaicaizi)
   - 使用 GitHub 的私信或邮件功能（如果公开可用）

**请包含以下信息：**
- 漏洞描述
- 重现步骤
- 潜在影响
- 建议的修复方案（如有）

**预期响应：**
- 我们将在 48-72 小时内确认收到你的报告
- 我们将调查并提供解决时间表的更新
- 问题解决后，我们会在安全公告中致谢（除非你希望匿名）

## Security Best Practices / 安全最佳实践

**For users / 用户须知：**

- Never commit or share files containing real personal data, company secrets, or financial details
- Review generated outputs before sharing publicly
- Keep your Agent and skill installations up to date

**不要提交或分享包含真实个人数据、公司机密或财务细节的文件**
**公开分享生成的输出前请仔细审查**
**保持你的 Agent 和 skill 安装为最新版本**
