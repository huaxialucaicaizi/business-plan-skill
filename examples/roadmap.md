本示例复用 [`financial-assumptions-and-validation.md`](./financial-assumptions-and-validation.md) 的验证、关键假设、Y1 收入推导和资金用途，以及 [`business-model.md`](./business-model.md) 的收入边界，不另编日期、合作方或客户名称。0–3 个月是与现有示例当前阶段一致的虚构阶段记录；3–18 个月均明确写成计划。真实项目必须用实际证据和自身计划替换。

## 18 个月路线图 / 18-Month Roadmap

| Stage / 阶段 | Key Actions / 关键行动 | Milestones / 可核验里程碑 |
|---|---|---|
| MVP 验证（0–3 个月；虚构阶段记录） | 在 M3 前完成 MVP；进行 18 人访谈（家长 12、学生 6）和 3 组小额广告测试（每组预算上限 ¥600）（均为已有虚构示例结果 / 示例假设） | M3 前记录 18 人访谈、80 人等候名单及 30 次引导式对话的评价；22 / 30 次被评为「能看懂」，同时记录 2 次知识点错误待修复（均为已有虚构示例结果）。本阶段不收费，与 M1–M3 新增付费客户为 0 一致（示例假设）。 |
| 商业化试点（3–6 个月；计划） | 计划从 M4 推出 ¥99/月个人月度会员；按 300 名新增付费客户/月进行 M4–M6 试点，并用真实数据验证注册 → 付费转化率、CAC 与月留存（均为示例假设；真实结果 `待补充`） | 计划到 M6 月末达到 813 名付费客户、MRR ¥80,487（示例假设推导）；是否达成以付费记录为准。真实注册 → 付费转化率与真实 CAC 为 `待补充`。 |
| 产品优化与推广（6–12 个月；计划） | 计划修复验证阶段发现的输出问题、优化产品，并按 1,000 名新增付费客户/月推进 M7–M12 获客（示例假设）；不同时启动未定价的学校 / B 端收入 | 计划到 M10 使月毛利覆盖 ¥250,000 月固定成本（不含获客支出），到 M12 月末达到 5,118 名付费客户、MRR ¥506,682；Y1 收入目标 ¥2,271,456（均为示例假设推导，以实际数据复核）。 |
| 后续扩展（12–18 个月；计划） | 在个人订阅验证后，计划评估学校 / 团体订阅及 B 端；合作方名称、定价、签约周期、客户数、收入和所需团队资源均为 `待补充` | 计划在假设补齐后再设可核验目标；在此之前，合作数量、客户数和 Y2 收入均为 `待补充`，不写成已签约或已实现收入。 |

## 与关键假设及资金用途对齐 / Alignment With Assumptions and Use Of Funds

- **收入起点：** M1–M3 不收费，M4 才计划出现付费客户，与财务示例的新增客户和 Y1 收入推导一致。
- **Y1 数字：** M6 的 813 人 / ¥80,487 MRR、M12 的 5,118 人 / ¥506,682 MRR，以及 Y1 ¥2,271,456，均直接复用财务示例的逐月推导（示例假设）。
- **收入边界：** Y1 只包括 ¥99/月个人订阅。¥899/年年度会员占比、学校 / 团体订阅和 B 端假设尚未完成，因此不计入本路线图的 Y1 目标。
- **资金用途：** ¥500 万融资的产品研发 40%、市场增长 30%、运营 20%、储备与合规 10% 均为已有示例假设。0–12 个月的产品 / 运营固定成本与获客支出由对应预算支持；12–18 个月扩展所需资源为 `待补充`，未假设已有额外预算。
- **小团队顺序：** 先完成 MVP 验证，再测试单一月度订阅和获客假设，之后才评估学校 / B 端；不把多个未验证收入模式并行写成既定成果。

## Roadmap Self-Check / 路线图自检清单（本虚构示例）

真实项目必须根据实际证据重新运行清单，不可直接沿用本示例的勾选结果。 / Real projects must re-run this checklist using their own evidence.

- [x] Each milestone states what, by when, and how success will be measured. / 每一阶段都写明交付内容、阶段截止点及核验记录或财务指标。
- [x] The first paid-user milestone and all 0–12 month customer/revenue targets match section 10 Key Assumptions and revenue derivation. / M1–M3 为 0，M4 起收费，M6 / M12 与逐月推导一致。
- [x] Roadmap actions are supported by the Use Of Funds allocation, or an explicit resource gap is shown. / 0–12 个月行动与已有资金用途对应；12–18 个月资源缺口写 `待补充`。
- [x] Unknown dates, names, partners, customers, and metrics are `待补充`, not invented. / 未编造日历日期、学校 / 合作方 / 客户名称或后续扩展指标。
- [x] The sequence is realistic for the stated team: validation precedes scaling and later-stage expansion is not overloaded. / 先验证月度订阅，再评估学校 / B 端，不并行承诺多个未验证模式。
- [x] Future milestones are written as plans/targets/assumptions rather than completed achievements. / 3–18 个月全部写成计划或示例假设；0–3 个月明确标为虚构阶段记录。
